# Election Candidate Transparency Archive  
## নির্বাচনী প্রার্থী তথ্য সংরক্ষণাগার

This project is an open public archive of election candidate disclosure documents.  
The goal is to make candidate financial and legal information easily accessible to citizens, researchers, and journalists.

এই প্রকল্পটি নির্বাচনে অংশগ্রহণকারী প্রার্থীদের প্রকাশিত তথ্যের একটি উন্মুক্ত সংরক্ষণাগার।  
এর লক্ষ্য হলো সাধারণ জনগণ, গবেষক ও সাংবাদিকদের জন্য প্রার্থীদের তথ্য সহজলভ্য করা।

---

## 📄 Available Documents | সংরক্ষিত নথি

For each candidate, the following official documents are provided (PDF):

1. **হলফনামা** (Affidavit)  
2. **নির্বাচনী ব্যয় ও ব্যক্তিগত সম্পদের বিবরণী** (Election Expense & Asset Statement)  
3. **আয়কর রিটার্ন** (Income Tax Return)

All documents are collected from publicly available official sources.

## 📂 Repository Structure

The repository is organized geographically:

### Structure Levels

- **Division** → বিভাগ  
- **District** → জেলা  
- **Constituency (AsHon)** → সংসদীয় আসন  
- **Candidate Folder** → প্রার্থীর নথি

## 🌐 Web Portal

This repository includes a searchable public interface.

Features:
- Division filter
- District filter
- Constituency filter
- Candidate name search
- Candidate photo
- Direct PDF access

Enable GitHub Pages to view:

**Settings → Pages → Deploy from branch → main → /root**

Live URL: https://siamuddin.github.io/candidate-details/
